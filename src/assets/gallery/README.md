# Gallery

Drop photos in here (`.jpg`, `.jpeg`, `.png`, `.webp`) and they appear in the
Gallery section on the Home page automatically — no code change needed.

They are sorted by filename, so prefix them if you want a particular order:

    01-mlsnext-fest.jpg
    02-witter-field.jpg

Keep them reasonably sized (roughly 1600px on the long edge is plenty). Large
phone photos make the site slow to load on a phone at the field.

Note: this repository is public, so anything placed here is publicly visible.
